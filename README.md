# ATAL FDP 2026 — Kings College of Engineering

A responsive, light-theme event website for the Faculty Development Programme on Data Analytics, AI and Edge Intelligence for Electrical Power and Energy Engineering.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and section navigation
- `assets/` — supplied campus/logo images and official brochure PDF

## Run locally
Open `index.html` in a browser. No build tools or package installation are required.

## Deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder (not only the ZIP).
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site.

Netlify and Vercel can also deploy this static folder directly.

## Important
- Registration buttons open the official ATAL Academy login portal: https://atalacademy.aicte.gov.in/login
- The map button opens the supplied Google Maps link.
- The website does not collect or store registration information. Applicants complete registration on the official ATAL portal.
- Review the event date, deadline, speaker names/designations, contact details, and official brochure before publishing.
